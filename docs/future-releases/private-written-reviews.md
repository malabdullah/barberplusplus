# Private written reviews — future release

Owner decision, 12 November 2026: retain the optional written-review work in the
isolated Supabase Test database and the earlier account-safety development branch.
It is not part of the current account tools release. Do not expose review entry
or staff review screens or promote its schema as a side effect of this work.

and barber scores. Written feedback is private to the permitted shop team and
admin. Current production star ratings remain available. Before a future release,
reconcile ownership and role access with current shared accounts, shop transfers,
managed barbers, booking history and rating rules, then obtain owner Test review.
