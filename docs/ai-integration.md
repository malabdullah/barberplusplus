# Retired messaging integration

WhatsApp/AI messaging workers, conversation screens and active integration
settings are retired. Historical records and the compatible `whatsapp_agent`
actor value are preserved; the UI labels that actor Agent. This identifier does
not enable messaging. Do not recreate the former Sulaiman/Anthropic/Meta workflow.

The earlier statement that no native customer implementation exists is obsolete.
iOS and Android are separate active customer repositories. Their actual
implemented/Test/staged/public states and any staff-app scope are maintained in
platform PRDs through Apps Manager; see [handoff](handoff.md),
[the current state snapshot](handoff-state.md) and [PRD](../PRD.md).

This retirement does not authorize deleting historical data, credentials or
provider resources. Follow [the retirement record](whatsapp-retirement.md) and
the current owner-approved resource manifest for any cleanup.
