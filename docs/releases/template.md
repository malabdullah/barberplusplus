# Release review

- Source commit:
- GitHub workflow run and attempt:
- Immutable frontend image:
- Backend source archive SHA-256:
- Ordered migration names/hashes:
- Existing production baseline adoption/rehearsal:
- Pending SQL and old/new compatibility:
- Exact production component compatibility:
- Encrypted off-host backup and restoration evidence:
- Previous frontend/Functions artifacts and tested rollback:
- Canonical domain, Auth redirects and management access:
- Application/backend/browser/security validation:
- Concrete initial cutover approval, when required:
- Actual running digest and commit after deployment:
- Production read-only smoke results:
- Remaining risks, monitoring and recovery owner:

Do not enter PASS until evidence supports it. Automatic rollback preserves
customer writes and committed SQL; database recovery is a separate procedure.
