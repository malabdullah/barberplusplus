# Canonical Barber++ artwork

For a combined logo use `barber-horizontal-{light,dark,mono-dark,mono-white}.svg`:
the mark replaces the initial B, followed by outlined **arber++**. The accessible
brand name remains **Barber++**. Keep the artwork LTR in every language.

Use `BrandLogo` for website UI. Preserve standalone `barber-wordmark-*` lettering,
`barber-symbol-*` marks and app icons. Legacy `barber-stacked-*` files are aliases
to the new horizontal master; the old duplicated-B composition is retired.
See [the complete rule](../../docs/logo-lockup.md).
